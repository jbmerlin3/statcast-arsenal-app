## 4. Judgment calls the user made. Do not silently revisit these.

Each was argued, measured, and decided. If you think one is wrong, **say so and
ask** — do not just change it.

1. **Every window is shaded, including one game.** `below_floor` renders filled,
   normal black text, keeping only its parenthetical n. The user was explicit:
   *"i know this is statistically a small sample, but this is what i want... it
   shows on any given day how he did."* A 60% whiff on 5 swings renders deep red
   with `(5)`. **The `(n)` is the only thing qualifying that number and is pinned
   by test. Never drop it.**

2. **Release traits grade on uniqueness** (`extreme` direction, `2*|p-50|`).
   Unusual slot is the thing that plays. **Extension is NOT extreme** — short
   extension is not a weapon.

3. **`rel_side` is negated but NOT arm-side mirrored**, unlike `hb`. Righty
   positive, lefty negative. It *was* mirrored briefly and reverted the same day:
   `hb`'s sign varies within a hand, release side's does not.

4. **VAA is raw, not residualised on `plate_z`.** The residual already exists in
   `02_StuffPlus/sc_fit_vaa_adj()` and is priced into Stuff+ two cells away.

5. **RV only, no RV/100.** RV/100 was built and removed the same day: split-half
   r = 0.02–0.10 at every sample. RV is a counting stat, takes no percentile.

6. **Traits table has no footnotes.** Three things are consequently invisible and
   not recoverable from it: whether Stuff+ is stale, that a sweeper's Stuff+ is a
   slider's, and whether a percentile came from a coarser cut.

7. **Release *side* deliberately NOT in Search.** A slider spanning −3.4 to +3.0
   is meaningless until you pick a hand. Open design question, not an oversight.

## 5. Traps that cost real time this session

**The deploy gate has been broken twice.** It compares `app_data` date,
`game_logs` date, code SHA, and now a `content` digest of `app_data`.
- A *backfill* changes values but no date and no commit → it skipped a deploy
  and reported success. That is why `content` exists.
- Then the stamp **write** listed fields by hand and never wrote `content`, so
  every stamp was unusable and every run redeployed unconditionally. Fixed in
  PR #5 by building the stamp from `have` plus a round-trip assertion.
- **A `NULL` from `deployed_dates()` is indistinguishable from "no stamp yet"**,
  which legitimately deploys. So gate bugs are silent. Always read the stamp.

**`repull_days` was 7, now 21.** Arm angle's backfill lands later than 7 days;
a date that falls out of the window is never re-fetched and freezes at NA.
August 2026 sat at 46.8% NA for three weeks with Savant holding the values.
`verify_traits.R` tier D now fails if this recurs.

**gt traps.**
- `cols_width()` evaluates its formula lazily — a local variable fails at
  *render* time. Bake the number into the formula string.
- `cols_label()` on an absent column errors. So does `cells_body()`.
- An inline lambda in a gt pipe fed `cols_label` a non-gt object and failed
  several calls later, naming the wrong function. Use a plain `if`.

**dplyr trap.** A column named `.d` partial-matches `mutate()`'s own `.data`
argument and is swallowed as a parameter — fails with `object 'x' not found` on
a frame that plainly has it. `.t` is fine; it matches no argument name.

**Savant's custom leaderboard echoes any selection name back as a header and
fills it with NA when the field is not real.** A bad field name looks exactly
like a successful fetch. Always check for all-NA before trusting it.

## 6. Verification, and what each check can and cannot see

```bash
for t in tests/*.R; do [ "$(basename $t)" = "phase1_artifacts.R" ] && continue
  echo "$(basename $t .R): $(Rscript $t 2>&1 | grep -E 'PASS|FAIL' | tail -1)"; done
Rscript scripts/phase1_check.R          # regression vs the original script
Rscript scripts/verify_traits.R         # 4 tiers: recompute, aggregate, physics, freshness
Rscript scripts/verify_arsenal_savant.R # external, per pitcher per pitch type
```

**All ten pass as of `ce2b8f1`.**

The distinction that matters:

- `phase1_check` and `step3_*` compare the app to **itself or an older itself**.
  They cannot catch a number that has been wrong since it landed.
- `verify_traits.R` tiers A/B recompute — a stale NA reconciles with itself
  perfectly, so they cannot see missing data either. **Tier D exists for that.**
- `verify_arsenal_savant.R` is the only external check at pitch-type grain
  (r = 0.995 on whiff%, 0.97 on run value over 1,141 cells). But it compares
  against pitchers Savant **returns**, which excludes ones whose value is
  missing. **A source that drops its own nulls cannot be used to find nulls.**

**VAA, release height and release side have NO external ground truth anywhere.**
Nobody publishes them at any grain. They are verified only by internal
recompute, physics, and league-value sanity.

### Recapturing a byte baseline

`tests/step3_null_identical.R --write` regenerates `chars_gt_null_baseline.rds`.
**Diff by column first and record what moved in the file's history block** —
every prior recapture did, and the block is how you tell a real regression from
a sanctioned change. My diff script initially reported *added* columns but not
*dropped* ones and read "nothing changed" on a table that had lost three.
Compare column sets in both directions.

## 7. Working style this user expects

- **Verify, don't assert.** Every claim about live state was checked against the
  stamp or the served HTML. "The run went green" is not evidence the app updated.
- **Measure before recommending.** Floors, reliability, denominators — this user
  will ask "what would it help" and expects numbers.
- **Say when you were wrong, plainly, and move on.** I was wrong three times about
  arm angle. Each correction improved the diagnosis. The user pushed back
  correctly on "Savant stopped publishing it" and was right.
- **Commit messages carry the reasoning**, including rejected alternatives with
  their measurements, so they are not re-proposed cold.
- **Never push or merge without asking.** Merging is the ship action: the gate
  reads the commit SHA, so it goes to the employer-facing link on the next run.
- Writeup style: verdict first, no em dashes, name the judgment call.
