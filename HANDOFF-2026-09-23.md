## 3. What is uncommitted on `vaa-adjusted`

### VAA is location-adjusted, app-wide

`adjust_vaa_for_location()` in R/features.R, called where VAA is derived. Per
pitch type, regress VAA on a quadratic in plate_z, take the residual, add back
the fit at that pitch type's mean plate height so the number stays an angle in
degrees rather than a residual on zero. A pitch type under `VAA_ADJ_MIN_N`
(2,000 rows) is left RAW, so fixtures and one-day frames pass through unchanged.

It sits at the derivation, so `app_data` and the `league_ref` built from it share
one fit by construction. Every surface that shows VAA is adjusted: Characteristics,
Search sliders, the Context chart, league percentiles.

Why: raw VAA's median within-pitcher SD was 1.52 times the spread between
pitchers, the worst ratio of any trait the app shows, because the same fastball
crosses flatter at the top of the zone than at the knees. Ben Joyce's 109-pitch
four-seam could not be ranked.

Measured before adopting, against a bar set before fitting (floor to 50 or lower,
correlation with raw 0.8 or better, still readable in degrees):

| | raw | adjusted |
|---|---|---|
| within/between SD ratio | 1.52 | 0.53 |
| pitches to settle a percentile within 5 points | 148 | 19 |
| corr with pitcher's own mean plate height (FF) | +0.430 | +0.021 |
| split-half reliability, odd vs even pitches (FF) | 0.969 | 0.999 |
| corr with release height (FF), physics the fit never saw | −0.76 | −0.83 |

Correlation between adjusted and raw at pitcher level: 0.912 on FF, 0.989 pooled.
Same trait, cleaned. Cost, disclosed: the median pitcher moves 8 percentile points
against the old ranking and the 90th moves 24.

Split-half reliability improves on all eight main pitch types (0.967-0.986 raw to
0.996-0.999 adjusted) and degrades on none. League means by type after adjustment:
FF −4.63, SI −5.75, FC −5.98, CH −7.37, ST −7.54, SL −7.64, FS −7.66, CU −9.53.

`tests/step10_vaa_adj.R` pins the three failure modes: it must actually adjust
(a no-op still renders), it must still track raw (or it has replaced the trait),
and it must not fire on a thin frame.

## 5. Measured, so it is not re-litigated

- **Per-trait shape floors**, n = (8r)^2 where r is the median within-pitcher SD
  over the SD of pitcher means, the count at which one standard error is worth
  about five percentile points: release height 4, release side 4, extension 10,
  velo 13, spin 14, **VAA 19** (was 148 before adjustment), ride 31, run 50.
  `tests/step9_context.R` re-derives all eight from app_data each run and fails if
  a stored floor drifts more than 1.6x, so these cannot go stale unnoticed.
- **External accuracy.** `scripts/verify_arsenal_savant.R` run live 2026-09-22
  against Savant's pitch-arsenal leaderboard, 1,218 pitcher-by-pitch-type cells:
  whiff% r = 0.9945 (MAE 0.68 points), pitches r = 0.9949, run value r = 0.9702,
  RV/100 r = 0.9649. Run value's sign confirmed against wOBA at −0.745. Counts run
  about 29 pitches light, which is the store-to-leaderboard lag, not a finding.
- **Internal consistency.** 400 random pitcher-by-side-by-pitch cells recomputed
  from raw rows and compared to the aggregator: 398 matched to four decimals, and
  the two that did not were KC and CS folding into CU per PITCH_CODE_RULES.
- **Release side** is negated from Savant's catcher-view x, so a righty reads
  positive (median +1.88 ft) and a lefty negative (−2.06). NOT arm-side mirrored,
  because the sign is pure handedness and percentiles are taken within hand.
- **The Arsenal usage bug** that prompted the floor rework: reading the cohort pool
  (50-pitch floor) hid Tolle's 43 FF and 19 CU vs LHH over the 2H and divided usage
  by what was left, reading his sinker as 58% instead of 38%.
- **Times through the order is feasible.** `n_thruorder_pitcher` is in the season
  store with no missing values: 408k pitches first time, 153k second, 74k third,
  1,490 fourth. 216 pitchers have 500+ pitches and reach a third time. Median
  pitcher-by-time cell 567 pitches. Crossed with count buckets, the median
  two-strike cell holds 182 pitches and the 10th percentile 31, so a 10%-to-25%
  usage shift is about four standard errors and readable, while the thin tail is not.

## 7. Traps that cost time this period

- **Nothing tests the server.** `ctx_cohort_rel()` was called by the release
  scatter and defined nowhere, so Details was broken for every pitcher for weeks
  with a green suite. The Arsenal hid pitch types and inflated usage. The chart
  refused to rank pitches the panel below it listed. All three were found by
  Jonathan looking at the page.
- **A floor built for one purpose reused for another.** `pitch_shape()`'s 50-pitch
  default exists so peer groups compare stable samples. Reusing that frame for a
  display panel silently dropped real pitches AND changed a denominator.
- **Joining app_data to the season store on (pitcher, game_date) is not unique.**
  It turned 636k rows into 39 million and produced a plausible-looking per-pitch-type
  table that was entirely wrong. app_data carries no pitch-level key. Recompute
  within one frame instead of joining.
- **A quadratic's fit at the mean is not the mean of its fits.** The adjusted VAA
  mean moves by 0.001 degrees, which is curvature, not a bug. A test asserting
  exact equality fails for the right reason and the wrong conclusion.
- **Selectize hides its options from the DOM.** `document.querySelectorAll('#ctx_pitch option')`
  returns only the selected one. Read `$('#ctx_pitch')[0].selectize.options`.
- **A test that encodes a claim will fail when the claim changes, and that is the
  point.** step9's "approach angle settles last" failed the moment VAA was
  adjusted. Update the assertion to the new fact and say why in the comment.
- **A fixture missing a column the aggregator reads** fails inside summarise()
  several frames away. step7's `arm()` needed `vaa`, then `release_pos_x`.
- **Checking a render:** gt tables and Search sliders render server-side, so
  grepping served HTML proves nothing. Use the browser pane, and confirm the server
  with `lsof -ti:7717` plus an HTTP 200 first.
